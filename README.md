# 🎭 디지털 공론장 실전 토론 시뮬레이터

하버마스의 담론 윤리에 기반한 **디지털 공론장 교육 프로그램**용 웹앱입니다.
고등학생이 스스로 제정한 가이드라인을 기반으로, 편향된 페르소나와 직접 합의의
과정을 거치는 공론장 시뮬레이션을 수행합니다.

> 연구문제: 하버마스의 담론 윤리에 기반한 디지털 공론장 교육 프로그램은
> 고등학생의 미디어 리터러시 역량 함양에 어떠한 영향을 미치는가?

## 실행 방법

서버가 필요 없는 정적 웹앱입니다.

- **로컬**: `index.html` 을 브라우저로 열면 바로 실행됩니다.
- **GitHub Pages 배포** (학생 배포용 권장):
  1. GitHub 저장소 → **Settings → Pages**
  2. Source: `Deploy from a branch` / Branch: `main` / 폴더: `/ (root)` → Save
  3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 주소가 생성됩니다.
     이 주소를 학생들에게 공유하세요.

## 3가지 실행 모드

| 모드 | API 키 | 비용 | 특징 |
|---|---|---|---|
| 🔌 **오프라인** (기본) | 불필요 | 무료 | 키워드 기반 숙의 감지 + 대본 엔진. 인터넷 없이도 동작. 판정이 결정적이고 투명함 |
| 🏫 **교사 프록시** | 교사 키 1개 (서버에 은닉) | 학급당 1차시 약 $3~5 | 자유로운 AI 대화. 학생은 키 불필요. 설치법: [PROXY_SETUP.md](PROXY_SETUP.md) |
| 🔑 **개인 키 직접** | 학생 각자 | 각자 부담 | Claude 또는 Gemini 키를 브라우저에 직접 입력 (테스트용) |

API 모드에서 연결이 실패하면 **자동으로 오프라인 엔진이 그 턴을 대신 처리**하므로
수업이 중단되지 않습니다.

## 교육 설계

- **페르소나 3종**: 도덕적 정당화형(진영이) / 이분법 강요형(프레임) / 피해의식 폭주형(희생양)
- **페르소나 변화 5단계**: 완전 공격 → 당황 조짐 → 방어벽 흔들림 → 논리 혼란 → 내적 모순 직면
  (대시보드에 실시간 표시)
- **숙의 감지**: 보편화 원리(U), 담화 원리(D), 공존 규칙 제안, 상호 존중·경청(부분 인정)을
  발화에서 감지해 점수와 판정 사유를 즉시 표시
- **AI 채점 (API 모드)**: 페르소나 응답을 구조화 JSON(대사+점수+판정 사유)으로 받아
  판정 사유를 학생 화면에 표시. 형식이 깨진 턴은 키워드 채점으로 자동 폴백
- **엔딩 2종**: ① 숙의 타결(합의 역량 100%) ② 공론장 위생 격리(자발적 거리두기)
- **페르소나 연속 도전**: 클리어한 페르소나는 ✅ 표시되고, 주제·입장·가이드라인을 유지한 채
  다음 페르소나에 도전. 세 유형 모두 합의를 이끌어내면 최종 완주 화면.
  이탈(엔딩 2)은 클리어로 인정되지 않으며 같은 페르소나 재도전 가능
- **SOS 3회**: 시스템 중재자가 상대 전술 분석과 숙의 전략 힌트 제공 (라운드마다 초기화)

## 연구 데이터 수집

토론 중·종료 후 **활동 기록을 파일로 저장**할 수 있습니다.

- `대화록 (.txt)` — 라운드별 구분선이 있는 전체 대화 + 턴별 판정·AI 판정 사유 + 라운드 요약
- `데이터 (.csv)` — 메타정보 + **라운드 요약 표**(페르소나·턴수·엔딩·SOS) + 턴 단위 데이터
  (엑셀에서 바로 열림). 여러 라운드를 진행해도 한 파일에 전부 누적 기록됩니다

학생 이름/학번은 1단계에서 입력받아 파일명과 기록에 포함됩니다.

## 파일 구성

```
index.html               메인 앱
style.css                스타일
app.js                   전체 로직 (오프라인 엔진 + API 연동 + 기록/저장)
proxy/cloudflare-worker.js  교사용 프록시 서버 코드
PROXY_SETUP.md           프록시 설치 가이드 (비용 안내 포함)
tests.html               자동 검증 페이지 (브라우저로 열면 59개 테스트 실행)
legacy/                  구버전 (동물실험 주제 고정 오프라인 버전)
```
